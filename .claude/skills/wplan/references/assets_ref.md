# wplan — bundled files

## Scripts

Runnable scripts shipped under the skill's `scripts/` directory.

### new-plan.sh

Extracts the verified plan/ template tarball into a destination folder.

**Run:** `scripts/new-plan.sh <destination-dir>   # creates <destination-dir>/plan` — shipped to `scripts/new-plan.sh`.

## Data files

Static data shipped under `assets/`.

### plan-template.tar.gz

The verified plan/ template: schema, gates, bootstrap specs, justfile, and both wdoc projections. — shipped to `assets/plan-template.tar.gz`.
