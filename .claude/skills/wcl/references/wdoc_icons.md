# Icons

Full **Lucide** and **Bootstrap Icons** packs ship compiled into the binary. No runtime disk read; only used icons are emitted into the output sprite (`_wdoc/icons.svg`). Icons paint with `currentColor`, so colour follows the surrounding text or class.

## Three ways to use an icon

```wcl
// 1. Inline pattern in a p (or span):
p "Status: :lucide.check: ready"

// 2. Placeable icon block (a legal diagram child):
diagram {
  width = 80  height = 80
  icon {
    name = "lucide.compass"
    x = 10.0  y = 10.0  width = 60.0  height = 60.0
  }
}

// 3. Badge on a shape — any rect/circle/container/process/...
//    accepts icon / icon_size / icon_pos / icon_class.
process "Validate" {
  id = v  width = 120.0  height = 50.0
  icon = "lucide.shield-check"
  icon_pos = :top_right
}
```

## Iconsets

Declare an `iconset` to rename a pack or set default styling. Per-icon `icon_def` children override individual icons within the set.

```wcl
iconset ui {
  pack  = "lucide"
  size  = "1.15em"
  color = "var(--wdoc-accent)"
  icon_def "heart" { color = "#bf616a" }
}

// Bare :name: now reads from the ui iconset:
p "We :heart: WCL."
```

## The placeable icon block

## Icons as a shape badge

Box-like shapes (`rect` / `circle` / `container` / `process` / `decision` / `terminator`, and custom `SvgBlock` shapes that declare the same fields) accept `icon` / `icon_size` / `icon_pos` / `icon_class` to stamp a badge over the shape. Live:

![diagram](../_wdoc/wdoc_icons-diagram-2.svg)

```wcl
process "Validate" {
  id = v  width = 160.0  height = 50.0
  icon = "lucide.shield-check"
  icon_pos = :top_right
}
```

## Icon-position symbols

When using `icon` as a shape badge, `icon_pos` accepts one of: `:center`, `:top_left` (default), `:top_right`, `:bottom_left`, `:bottom_right`, `:left`, `:right`.
