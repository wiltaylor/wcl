# The lessons loop

_lessons.wcl captures what each run teaches; durable lessons flow back into this wskill's template and content._

During and after implementation runs, record durable observations in lessons.wcl: what confused agents, which boundaries were violated, which spec shapes worked. When a project wraps, review lessons.wcl with the user and fold general lessons back into this wskill - its template (the `wplan` built-in of `wcl init`, canonical at crates/wcl/src/scaffold/templates/wplan.wcl in the WCL repo) and its reference content.
